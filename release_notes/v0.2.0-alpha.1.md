## What's new in 0.2.0-alpha.1

- **Leela comes with Gifu:** Leela 0.11, rebuilt for current systems (no extra libraries; CPU and GPU versions). No separate download in Engine setup.
- **Play against Leela:** choose the AI opponent (KataGo, Leela…) in New game. Games record the engine that played under its own name.
- **Leela analyses:** live candidates, Analyze game and Compare work with Leela. Leela gives no score, so scores show "–" instead of a made-up 0. KataGo's and Leela's analyses are stored side by side and never overwrite each other; the Deep report switches between them.
- **One engine on the GPU at a time:** while Leela plays, KataGo pauses and comes back when the game ends (running both on one GPU could hang the computer).
- **Analysis stops when done:** live analysis stops at a number of visits per position (default 5000; Settings).
- **Resign:** a Resign button and Game menu item record the result and return to the analysis layout.
- **Keys:** rebind, add or clear keys per command in Settings → Keys; reset all. Only stepping keys repeat when held.
- **Number fields:** type a value, with − / + right beside it (Shift: ten steps; the mouse wheel works too).
- **Fixes:** Save / Save as did nothing for new games on Windows; a log file (gifu.log in the settings folder) and slow-frame logging help track down freezes.
