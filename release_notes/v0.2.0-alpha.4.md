## What's new in 0.2.0-alpha.4

### KataGo's transformer networks
- **New networks in Engine setup:** KataGo's transformer networks can be downloaded with one click, in three sizes. **Transformer S** (40 MB) is smaller than the recommended 18-block network and stronger per visit. **Transformer M** (95 MB) plays about as strong as the 28-block network at a lower cost per evaluation. **Transformer L** (250 MB) is the strongest. Pick one in Settings → KataGo → Network.
- **Speed depends on your GPU and engine build:** the transformers are fastest with KataGo's NVIDIA builds. On the OpenCL build (Intel, AMD and most GPUs) the large one can be much slower than the 18-block network; Transformer S or M is the better choice there.
- The first start with a new network on OpenCL tunes the GPU for it, which can take a few minutes. The new Console (below) shows that progress.

### Console
- **View → Console (F8),** or click the engine status at the top right: everything Gifu and its engines say to each other. That includes KataGo's start-up (the device and backend it found, GPU tuning, which networks it loaded), the commands Gifu sends and the engine's replies, errors, and Gifu's own log.
- Filter by kind, **Copy** the lines (handy for bug reports), and type your own engine commands (GTP) to send to the running engine.

### Fixes
- **Analysis no longer stops after a minute:** KataGo's example settings stopped live analysis after 60 seconds on each position. Gifu now lifts that limit, so "Stop analysing a position at" (Settings → Analysis; 0 = never) decides.
- **Human moves show the right player:** on positions set up with stones (including stones placed with the Markup tools), the Human moves overlay could show Black's likely moves when it was White's turn.
