## What's new in 0.2.0-alpha.2

- **Toolbar icons:** the toolbar uses icons, with tooltips that show each button's name and key. Settings → Appearance switches the analysis and play buttons back to names. New buttons: candidates, A1 coordinates, and move numbers (All / 1 / 5 / 10 / none).
- **Human strength** dropdown next to Human moves while they are shown.
- **Dropdowns** for long lists (theme, engines, networks, human strength, human win rate): the arrow keys change the choice and apply it as you go. Text that doesn't fit is shortened with "…" everywhere.
- **Engines:** GPU engines are listed first. Downloading an engine stops the running ones first, so an existing KataGo no longer blocks the update on Windows.
- **Fixes:** the Komi dialog no longer closes as soon as it opens; tab labels shrink to fit.
- **Leela:** smaller copies of its network (half size and smaller) for faster downloads.
